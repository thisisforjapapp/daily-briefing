    Keep Daily Learning on your phone

    iPhone · Safari

    1. Open the permanent homepage in Safari.
    2. Tap Share, then Add to Home Screen (look under More if needed).
    3. Enable Open as Web App if offered, then tap Add.

    Android · Chrome

    1. Open the permanent homepage in Chrome.
    2. Use Install Daily Learning when available, or open Chrome’s ⋮ menu.
    3. Choose Add to Home screen or Install app, then confirm.

    Menu names vary by browser and version. If installation is unavailable, bookmark the homepage and read in your normal browser.

    Add the homepage once, rather than a dated edition. Open online to check for new briefings; the app does not refresh while closed. App updates wait for your Reload choice.
